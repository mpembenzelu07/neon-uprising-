# NEON UPRISING

An open-world browser game built with Three.js + Vite. Runs on GitHub Pages.

## Deploy in 4 steps (no PC needed)

1. Create a GitHub repo named `neon-uprising` (public).
2. Click **Code → Codespaces → Create codespace on main**.
3. Upload all files above to the repo (drag-drop in the Codespace file tree).
4. Push — the GitHub Action deploys automatically. Then:
   - Repo **Settings → Pages → Source: GitHub Actions**.
   - Your game will be live at `https://<username>.github.io/neon-uprising/`.

## Alternative: CodeSandbox (easiest)

1. Go to https://codesandbox.io
2. Create new → "Import from GitHub" → paste your repo URL.
3. Click **Preview** — the game runs instantly in browser.
